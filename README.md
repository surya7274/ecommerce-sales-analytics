# Project Title: E-commerce Sales & Customer Analytics

## Problem Statement
Analyze an e‑commerce platform's sales, customer behavior, and delivery performance to uncover actionable insights that can drive revenue growth, improve customer retention, and optimize operations.

## Dataset
Synthetic version of the Olist Brazil e‑commerce dataset (generated by `generate_synthetic_data.py`). The data mimics real‑world multi‑table relationships across customers, orders, order items, products, payments, and reviews.

## Tech Stack
- **Python** (pandas, numpy, scikit‑learn)
- **PostgreSQL** (SQLAlchemy, psycopg2)
- **SQL** for business queries
- **Power BI** for interactive dashboard

## Architecture / Workflow Diagram
```
raw CSVs → clean_data.py → cleaned CSVs → feature_engineering.py → processed CSVs → load_to_postgres.py → PostgreSQL DB → business_queries.sql → insights → Power BI dashboard
```

## Key Insights (example placeholders – replace after running analysis)
- **Monthly Revenue**: $1.2 M in Dec 2022, 12 % MoM growth.
- **Top Product Category**: Electronics contributed 35 % of total revenue.
- **Repeat Customer Rate**: 27 % of customers placed >2 orders.
- **Delivery Delay Impact**: Orders delayed >7 days have an average review score 0.8 points lower.

## Business Recommendations
1. **Focus marketing on high‑value repeat customers** – they generate 45 % of revenue.
2. **Improve logistics for high‑delay regions** (e.g., North‑East) to boost review scores.
3. **Cross‑sell accessories** in the Electronics category, which shows the highest average order value.

## How to Run (step‑by‑step)
1. **Clone repo**
   ```bash
   git clone <repo‑url>
   cd ecommerce-sales-analytics
   ```
2. **Create a virtual environment & install dependencies**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. **Generate synthetic data** (or replace with real Olist CSVs)
   ```bash
   python src/generate_synthetic_data.py
   ```
4. **Run cleaning & feature engineering notebook**
   ```bash
   jupyter notebook notebooks/01_cleaning_and_feature_engineering.ipynb
   ```
5. **Configure PostgreSQL connection** – copy `.env.example` to `.env` and fill in your credentials.
6. **Load data into PostgreSQL**
   ```bash
   python src/load_to_postgres.py
   ```
7. **Execute business queries**
   ```bash
   psql -f sql/business_queries.sql
   ```
8. **Build Power BI dashboard** – follow `powerbi/dashboard_build_guide.md`.
